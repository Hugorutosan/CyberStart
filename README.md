# CyberStart 🛡️

**Aprende ciberseguridad defensiva, paso a paso.**

CyberStart es una pequeña plataforma educativa en español para aprender fundamentos de seguridad digital mediante una ruta guiada, retos interactivos y enlaces a recursos fiables.

![CyberStart](https://img.shields.io/badge/status-educational-8b7cff)
![License](https://img.shields.io/badge/license-MIT-55d6d0)
![No dependencies](https://img.shields.io/badge/dependencies-none-6ee7b7)

## ✨ Funciones

- Diseño adaptable a móvil, tablet y ordenador.
- Cuatro retos interactivos con explicaciones.
- Progreso guardado en el navegador mediante `localStorage`.
- Recursos externos de formación y buenas prácticas.
- No necesita cuenta, servidor ni instalación.
- No realiza escaneos ni interactúa con sistemas externos.

## 🚀 Cómo ejecutarlo

**Opción 1:** abre `index.html` en tu navegador.

**Opción 2:** utiliza la extensión Live Server de Visual Studio Code:
1. Abre la carpeta del proyecto en VS Code.
2. Instala la extensión Live Server.
3. Haz clic derecho en `index.html`.
4. Selecciona **Open with Live Server**.

## 🧭 Publicarlo con GitHub Pages

1. Sube todos los archivos de este proyecto a un repositorio de GitHub.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Pulsa **Save** y espera a que GitHub Pages publique el sitio.
